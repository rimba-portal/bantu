# Admin Panel Help

## Purpose

The Admin panel is the platform governance and configuration workspace. Use it to maintain shared foundation data, authorization controls, and platform-level configuration.

## Foundation

| Navigation Item | What You Can Do |
|---|---|
| **Classifications** | Maintain global classifications and taxonomies. |
| **Categories** | Maintain platform categories. |
| **Settings** | Maintain global application settings. |
| **Metadata** | Maintain platform metadata and definitions. |

## Security

| Navigation Item | What You Can Do |
|---|---|
| **Roles** | Maintain authorization roles. |
| **Permissions** | Maintain permission definitions and role capabilities. |

## Platform

| Navigation Item | What You Can Do |
|---|---|
| **Panels** | Configure application panels. |
| **Navigation** | Configure navigation structure and menus. |
| **Themes** | Configure platform branding and themes. |
| **Packages** | Configure installed Rimba packages and modules. |

## Administration Guidance

- Apply the principle of least privilege when managing roles and permissions.
- Keep classifications, categories, metadata, and settings reusable across packages.
- Treat panel, navigation, theme, and package changes as platform-wide configuration.
- Validate the affected user experience after changing shared configuration.
